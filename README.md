# Redux Movie DB

Professional, responsive React app showcasing movies using The Movie Database (TMDB) API.

This is a portfolio project demonstrating modern React, Redux Toolkit state management,
and a focused UI built with Chakra UI. It provides discoverable movie listings, flexible
filters, search, and detailed movie views.

**Note:** This is a portfolio project and intentionally does not include a license file.

## Key Features

- Discover movies: Trending, Popular, Now Playing, and Upcoming
- Sidebar filters: genre, year, language, minimum user score, sort options
- Live search with instant suggestions
- Movie details with cast and similar titles
- Smooth skeleton loading and responsive layout

## Tech Stack

- React 18
- Redux Toolkit (slices + createAsyncThunk)
- Chakra UI
- react-router-dom v6
- Axios (TMDB API)

## Quick Start

1. Clone the repository and install dependencies:

```bash
git clone https://github.com/moteeb-asad/redux-movies-db.git
cd redux-movies-db
npm install
```

2. Create a `.env` file in the project root with your TMDB API key:

```env
REACT_APP_TMDB_API_KEY=your_tmdb_api_key_here
```

3. Start the development server:

```bash
npm start
```

4. Create a production build:

```bash
npm run build
```

## Environment

- The app requires a TMDB API key set in `REACT_APP_TMDB_API_KEY`.
- Node.js v16+ is recommended.
